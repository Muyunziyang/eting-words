              E听说单词通 · 网页 / 安卓版  使用说明
══════════════════════════════════════════════════════════════
版本：v1.0.0（网页/安卓独立版，词库数据与桌面版 v1.3.0 一致）
数据：18 个内置词库，共 57,805 词（小学/初中/高中译林版·2024新教材、
      中考、高考、新概念英语、四六级(分册)、考研、雅思、托福、PETS1-4 等）

────────────────────────────────────────────────────────────
一、如何"装"到手机（安卓）
────────────────────────────────────────────────────────────
本程序是网页应用（PWA），无需应用商店，按下述任一方式即可像 App 一样
离线使用：

方式 A（推荐，可离线、有启动图标、全屏运行）：
  1. 用 安卓 Chrome / Edge 打开本应用网址（或本地打开 index.html 后
     部署到任意静态空间 / 局域网服务器）。
  2. 点浏览器右上角「⋮」→「添加到主屏幕 / 安装应用」。
  3. 桌面出现「E单词通」图标，点开即为独立全屏 App，断网也能用。

方式 B（无安装提示时兜底）：
  浏览器菜单 →「添加到书签」或「添加到主屏幕」，同样可一键进入。

提示：
  • 朗读依赖浏览器语音合成（Web Speech API）。请使用 安卓 Chrome /
    Edge；首次点击「🔊朗读」时若无声，请在系统「设置 → 无障碍 →
    文字转语音输出」中确认引擎已安装（推荐 Google 文字转语音）。
  • 首次打开需联网加载词库；之后 Service Worker 会缓存全部数据，
    可完全离线使用。
  • iOS（Safari）同样可用：分享 →「添加到主屏幕」。功能一致，
    仅朗读音色由系统决定。

────────────────────────────────────────────────────────────
二、本地直接运行（电脑）
────────────────────────────────────────────────────────────
  1. 进入本文件夹，启动一个静态服务器，例如：
       python -m http.server 8080
  2. 浏览器打开 http://localhost:8080
  注意：必须用 http(s) 方式打开（不能直接双击 index.html 用 file://
        打开），否则 Service Worker 与词库懒加载会被浏览器拦截。

────────────────────────────────────────────────────────────
二（续）、手机怎么访问（三种方式）
────────────────────────────────────────────────────────────
前提：手机和电脑必须在"同一网络环境"下才能直连（见方式 1）。
重要限制：Service Worker（离线缓存 + 安卓 Chrome 完整"添加到主屏
幕"）要求"安全上下文"= HTTPS 或 localhost。手机用 http://局域网IP
访问属不安全上下文，应用功能完全可用，但离线缓存不生效、Chrome 可能
只生成普通书签（iOS Safari 不受影响，可直接加到主屏）。

【方式 1 · 局域网直连（最快，2 分钟，仅本机 WiFi 内可用）】
  1) 进入本文件夹，双击 start_phone_server.bat
     （它会自动监听局域网并打印形如 http://192.168.x.x:8000 的地址；
      若手动启动，必须用：
        python -m http.server 8000 --bind 0.0.0.0
      注意：缺 --bind 0.0.0.0 时只监听 127.0.0.1，手机连不进来）。
  2) 手机连同一个 WiFi，浏览器打开上面打印的 http://192.168.x.x:8000
  3) 安卓 Chrome 点「⋮」→「添加到主屏幕」即可像 App 一样全屏打开。
  说明：首次弹防火墙提示请"允许"；不用时关掉窗口 / Ctrl+C 停止。

【方式 2 · HTTPS 隧道（推荐，手机能当真 App + 还能用流量）】
  把本地 8000 端口暴露成一个 https 公网地址，手机打开即为安全上下文，
  PWA 离线/安装完整可用：
    • Cloudflare Tunnel（免账号，最稳）：
        cloudflared tunnel --url http://localhost:8000
      得到 https://xxxx.trycloudflare.com，手机打开即可。
    • 或 ngrok：   ngrok http 8000
    • 或 localtunnel： npx localtunnel --port 8000
  然后手机打开该 https 链接，点「添加到主屏幕」即得到可离线 App。

【方式 3 · 部署到静态托管（一劳永逸，家人朋友也能用）】
  把整个 webapp/ 文件夹上传到任意静态空间，得到固定 https 域名：
    • GitHub Pages：仓库放 webapp/，设置 Pages 指向该分支/目录。
    • Netlify / Cloudflare Pages：直接拖拽 webapp/ 文件夹上传。
    • 国内可用：Gitee Pages、腾讯云 COS / 静态网站托管等。
  注意：托管后根目录要有 index.html 与 manifest.webmanifest。

────────────────────────────────────────────────────────────
三、功能一览
────────────────────────────────────────────────────────────
  • 词库浏览：18 个词库按单元列出，可逐级展开查看单词/音标/释义/例句。
  • 学习模式：单词卡（音标、释义、例句、听说），支持朗读、跟读提示、
             上一词/下一词、收藏、标记错误。
  • 听写模式：听音拼写，支持释义提示、显示答案，答错自动入错题本。
  • 填空模式：三种题型——全文默写 / 隐藏字母 / 顺序打乱，可设遮挡比例。
  • 错题本：自动收集答错单词；支持单条删除、批量清空（二次确认）。
  • 收藏：单词卡「收藏」一键加入；收藏页可复习、朗读、单删、清空。
  • 设置：8 套主题配色、语速/音量/重复次数、答题倒计时开关与秒数、
         打乱顺序、填空遮挡比例、正文字号、显示音标/例句等。
  • 统计：累计学习词次、正确率、正确/错误数；一键重置（二次确认）。
  • 导入/导出：导入自定义 .txt 词库（与桌面版同格式）；导出默写单、
             导出词库；下载导入模板。
  • 帮助：内置功能说明。

────────────────────────────────────────────────────────────
四、词库 .txt 导入格式
────────────────────────────────────────────────────────────
  单词|音标|释义|例句|例句翻译
  用 #name: 标注词库名，#unit: 标注单元名。每行一条，字段用「|」分隔，
  字段内不要出现「|」。例：
    #name: 我的词库
    #unit: Unit 1 示例
    apple|ˈæpl|苹果|I like apples.|我喜欢苹果。
    book|bʊk|书|This is a book.|这是一本书。

────────────────────────────────────────────────────────────
五、与桌面版(EXE)的关系
────────────────────────────────────────────────────────────
  词库、学习/听写/填空/错题/收藏/统计逻辑与桌面版完全一致，可视为
  同一套数据的"手机/网页形态"。桌面版擅长批量导入导出与打印默写单；
  网页/安卓版胜在随手可背、可离线、免安装。
  数据保存在本机浏览器（localStorage），清除浏览器数据会清空
  错题本/收藏/统计/我的词库，建议重要内容及时导出备份。
