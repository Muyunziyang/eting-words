              E听说单词通 · 网页 / 手机版  使用说明
══════════════════════════════════════════════════════════════
版本：v1.3.0-web（词库数据与桌面版 v1.3.0 完全一致）
数据：18 个内置词库，共 57,805 词
      （小学/初中/高中译林版·2024 新教材、中考、高考、新概念英语、
       四六级分册、考研、雅思、托福、PETS1-4 等）

一句话介绍：
  这是一个"网页版背单词 App"，不用去应用商店下载安装，用手机浏览器
  打开网址就能用；还能"放到手机桌面"像普通 App 一样点开。
  数据存在你手机浏览器里，电脑关不关机都不影响使用。


────────────────────────────────────────────────────────────
一、最推荐的使用方式（你已经在用了）
────────────────────────────────────────────────────────────
你已经把应用部署到了 GitHub Pages，得到一个固定网址：

        https://muyunziyang.github.io/eting-words/

手机上这样用：
  1. 用手机任意浏览器（QQ 浏览器 / 夸克 / Chrome / Safari 都行）
     打开上面这个网址。
  2. 把它"放到桌面"，以后点图标就能进：
       • 安卓 · Chrome：点右上「⋮」→「安装应用 / 添加到主屏幕」
       • 安卓 · QQ 浏览器：点底部「≡」菜单 →「添加到桌面」
       • 安卓 · 夸克：点底部「≡」菜单 →「添加到主屏幕」
       • 苹果 · Safari：点「分享」→「添加到主屏幕」
  3. 桌面出现「E单词通」图标，点开就是全屏 App。

说明：
  • 这个网址是固定的，电脑关机、断网都不影响它存在（数据存在云端）。
  • 手机要听发音时需要联网（见第三节）。


────────────────────────────────────────────────────────────
二、关于"朗读发声"（重点，和以前不同了）
────────────────────────────────────────────────────────────
以前版本依赖手机系统自带的语音引擎，在 QQ 浏览器、夸克等浏览器里
经常没声音。现在改成：

      🔊 朗读 = 在线播放发音音频（有道词典 / 谷歌翻译）

好处：
  • 不挑浏览器：QQ 浏览器、夸克、Chrome、Safari、Firefox 都能响，
    不用再去手机"设置 → 无障碍 → 文字转语音"里折腾。
  • 不挑手机：荣耀、小米、华为、OPPO 等都不用配置。

前提：
  • 需要联网（在线音频要现下载）。完全断网时，会自动退回手机系统
    语音（仅部分浏览器支持，通常还是 Chrome 最稳）。

怎么用：
  • 单词卡点「🔊」听单词；点「🔤」逐字母拼读。
  • 设置里有「重复次数」（1~5 遍）：把同一条连读几遍，代替"调速"。
  • 设置里有「朗读中文释义」开关：打开后顺带读中文意思
    （中文走谷歌翻译发音，国内网络偶尔偏慢，可选）。

注意：在线音频语速是固定的，所以设置里没有"语速/音量"滑块了
      （这两项对在线发音无效，已移除）。


────────────────────────────────────────────────────────────
三、功能一览
────────────────────────────────────────────────────────────
  • 词库浏览：18 个词库按单元列出，逐级展开看 单词/音标/释义/例句。
  • 学习模式：单词卡（音标、释义、例句、听说），可朗读、收藏、标记错误。
  • 听写模式：听音拼写，释义提示、显示答案，答错自动进错题本。
  • 填空模式：三种题型——全文默写 / 隐藏字母 / 顺序打乱，可设遮挡比例。
  • 错题本：自动收集答错单词；支持单条删除、批量清空（二次确认）。
  • 收藏：单词卡「收藏」一键加入；收藏页可复习、朗读、删除、清空。
  • 设置：8 套主题配色、重复次数、朗读中文释义、答题倒计时、打乱顺序、
         填空遮挡比例、正文字号、显示音标/例句等。
  • 统计：累计学习词次、正确率、正确/错误数；一键重置（二次确认）。
  • 导入/导出：导入自定义 .txt 词库；导出词表、生成可打印默写单。
  • 帮助：应用内自带功能说明。


────────────────────────────────────────────────────────────
四、自己重新部署 / 更新（仅供参考）
────────────────────────────────────────────────────────────
如果以后要改词库、改功能，重新上传到 GitHub 即可：

  1. 把 webapp/ 文件夹里"所有内容"（index.html、manifest.webmanifest、
     sw.js、.nojekyll、css/、js/、assets/、data/）传到仓库根目录。
     —— 注意：是选 webapp 里面的文件和文件夹，不是把 webapp 这层
        文件夹本身传上去，否则网址会多一层路径导致打不开。
  2. 仓库「Settings → Pages → Source 选 Deploy from a branch →
     Branch 选 main、目录选 /(root) → Save」。
  3. 等 1~2 分钟，网址自动更新（手机端把 App 彻底关掉重开即刷新）。

其他托管方式（得到固定 https 网址，任选其一）：
  • Netlify / Cloudflare Pages：直接把 webapp/ 文件夹拖上去。
  • 国内：Gitee Pages、腾讯云 COS 静态网站托管等。


────────────────────────────────────────────────────────────
五、词库 .txt 导入格式
────────────────────────────────────────────────────────────
  每行一条，字段用「|」分隔，字段内不要出现「|」：
      单词|音标|释义|例句|例句翻译
  用 #name: 标注词库名，#unit: 标注单元名。例：
      #name: 我的词库
      #unit: Unit 1 示例
      apple|ˈæpl|苹果|I like apples.|我喜欢苹果。
      book|bʊk|书|This is a book.|这是一本书。


────────────────────────────────────────────────────────────
六、与桌面版(EXE)的关系
────────────────────────────────────────────────────────────
  词库、学习/听写/填空/错题/收藏/统计逻辑与桌面版完全一致，可视为
  同一套数据的"手机 / 网页形态"。桌面版擅长批量导入导出与打印默写单；
  网页 / 手机版胜在随手可背、免安装、跨设备。
  数据保存在本机浏览器（localStorage）：清除浏览器数据会清空
  错题本 / 收藏 / 统计 / 我的词库，重要内容请及时导出备份。
